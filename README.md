# 포켓 셀즈 (Phaser 3)

《데드셀》·《스컬》 스타일 2D 횡스크롤 액션 로그라이트 포켓몬 팬게임입니다. 개인·비상업 용도로만 사용하세요.

## 실행

```bash
npm install
npm run fetch-assets   # 도트 스프라이트·AnimData.xml·초상화·아이템 그림 자동 다운로드 (이미 받은 파일은 건너뜀, --force 로 재다운로드)
npm run dev            # http://127.0.0.1:5173
```

배포용 빌드는 `npm run build` → `dist/` 폴더.

다른 컴퓨터에서 이어서 개발할 때: 소스는 저장소의 `main` 브랜치(`gh-pages` 브랜치는 빌드된 게임만 있다). 스프라이트·영상은 저장소에 같이 들어 있어 `fetch-assets` 없이 바로 된다.

```bash
git clone -b main https://github.com/strongdragon98-art/pokecells.git
cd pokecells
npm install
npm run dev
```

고친 뒤에는 `git add -A` → `git commit` → `git push` 로 소스를, `npm run deploy` 로 게임을 올린다. ZIP·한 파일 테스트판은 `.gitignore` 로 빠져 있어 필요하면 그 컴퓨터에서 다시 만든다.

### 다른 사람에게 보낼 단일 HTML

```bash
npm run build:single   # → 포켓셀즈-테스트.html (약 1.4MB, 서버 없이 더블클릭으로 실행)
```

스프라이트는 좌우 2방향만 잘라 팔레트 PNG 로, 글꼴은 게임에 쓰인 글자만 남겨 파일 안에 담습니다. 게임을 고친 뒤에는 이 명령을 다시 실행해 파일을 새로 만드세요.

### 테스터 배포용 ZIP

```bash
npm run package   # 게임 마크 생성 → 단일 HTML 빌드 → 포켓셀즈_테스트판.zip
```

함께 생기는 `포켓셀즈_웹업로드용.zip` 은 최상위에 `index.html` 하나만 들어 있어 정적 호스팅에 그대로 올릴 수 있습니다.

### itch.io · 아이폰용 ZIP

```bash
npm run package:itch   # vite build → dist/ → pokecells-itch-mobile.zip (최상위 index.html · 파일 약 585개 · 약 18MB)
```

`vite.config.js` 가 `base: './'` 라 itch.io(`html-classic.itch.zone/html/<번호>/`)·GitHub Pages 처럼 하위 경로에 올려도 이미지·영상·글꼴 경로가 깨지지 않습니다. itch.io 에서는 Kind of project = HTML → ZIP 업로드 → "This file will be played in the browser" 체크 → Embed options 에서 Mobile friendly(Landscape)·Fullscreen button 을 켜세요.
아이콘을 바꾸려면 `npm run make-pwa-icons` (`brand/pokecells-mark.png` → `public/pwa/`).

### GitHub Pages (24시간 웹 주소)

```bash
npm run deploy   # predeploy 가 npm run build 를 먼저 돌리고 → gh-pages 가 dist/ 를 gh-pages 브랜치에 올린다
```

라이브 주소: **https://strongdragon98-art.github.io/pokecells/** (저장소 `strongdragon98-art/pokecells`, 올린 뒤 1~2분이면 반영). 처음 올릴 때 GitHub 로그인 창이 뜨면 직접 로그인하고, 그 뒤로는 기억된다. 업로드 기록의 작성자는 실제 메일 대신 GitHub 가림용 주소(`strongdragon98-art@users.noreply.github.com`)이고, `--nojekyll` 로 GitHub 의 Jekyll 변환을 건너뛴다. 공개 주소라 링크를 아는 누구나 접속할 수 있다.

### 휴대폰 · 아이폰 (`index.html` · `public/manifest.json` · `src/systems/Mobile.js` · `src/systems/TouchControls.js`)
- 홈 화면에 추가(PWA): `manifest.json`(`display: fullscreen` · `orientation: landscape` · 아이콘) + 애플 메타 태그(`apple-mobile-web-app-capable` · `black-translucent` 상태 바 · 이름 「포켓셀」). 아이폰 사파리는 웹페이지 전체화면 API 가 없어서, 주소창 없는 진짜 전체화면은 **공유 → 홈 화면에 추가** 한 아이콘으로 실행할 때만 됩니다. 사파리로 처음 열면 로비 왼쪽에 이 방법을 알려 주는 안내가 뜨고(닫으면 다시 안 뜸), itch.io 페이지 안(iframe)이면 게임만 새 창으로 여는 링크를 함께 줍니다.
- 화면 고정: `html, body` 는 보이는 높이(`100dvh` → 주소창 변화까지 반영한 `--app-h`)에 맞추고 스크롤·핀치·두 번 탭 확대·텍스트 선택·길게 누르기 메뉴를 막습니다. 게임 캔버스는 노치·다이내믹 아일랜드·홈 바를 피한 안전 영역(`env(safe-area-inset-*)`) 안에서 Phaser `Scale.FIT` + `CENTER_BOTH` 로 맞추고, 회전·창 크기·`visualViewport` 가 바뀌면 바로(아이폰은 회전 뒤 몇 번 더) 다시 맞춥니다.
- 세로로 들면 할로우 나이트풍 안내(「📱 원활한 플레이를 위해 아이폰을 가로(Landscape)로 돌려주세요」)가 덮고 던전은 일시정지됩니다. 가로로 돌리면 바로 보이고, 일시정지 메뉴의 「계속하기」로 이어서 합니다. 안드로이드는 첫 터치에 전체화면 + 가로 고정을 시도합니다.
- 가상 패드: 터치 화면이면 자동으로 켜지고, 위쪽 가운데 🎮 ON/OFF 버튼으로 끄고 켤 수 있습니다(고른 값은 기억). 멀티터치(`input.activePointers: 4`)라 이동하면서 점프·스킬·대시를 동시에 누를 수 있습니다.
  - 왼쪽 아래: 엄지를 댄 자리가 중심이 되는 조이스틱 (아래로 당기고 점프 = 발판 아래로)
  - 오른쪽 아래 부채꼴: 점프(가장 크게) · Z · X · C · 대시 · 교대 · 조사(F — 센터·자판기·아머까오·표지판·기술머신 앞에서 금빛으로 맥동) · Z기술 · 메가
  - Z기술은 Z크리스탈을, 메가는 메가스톤을 얻기 전엔 아예 보이지 않는다 (메가는 3단 진화 전이면 흐리게, 메가진화한 뒤엔 다시 숨는다).
  - 위쪽: 큼직한 지도 · 가방 · 일시정지 (화면 맨 위 가장자리에서 조금 내려 둠 — 사파리 가로 화면은 맨 위를 탭하면 주소창이 나온다). 지도·가방 창 왼쪽 위의 큰 [지도] [가방] 탭으로 바로 오가고, 오른쪽 위 [✕ 닫기]. 터치패드를 쓰면 알림은 아래 가운데(조이스틱과 버튼 사이)에 두 줄까지 접혀 뜨고, 화면 안내 문구도 「조사 버튼」처럼 버튼 이름으로 바뀝니다.
- 메뉴는 모두 손가락만으로 됩니다: 로비 탭·초상화·편성·던전 입장, 컷신 건너뛰기, 기술머신 카드 뒤집기·고르기·결정·슬롯, 아머까오 목적지, 지도 탭·이동·확대·닫기, 가방, 일시정지·결과 화면.

압축을 풀면 `포켓셀즈 테스트판/` 폴더에 `▶ 게임 시작하기.html`(실행), `포켓셀즈 게임마크.png`, `읽어주세요.txt` 가 들어 있습니다. html 을 열면 게임 마크가 시작 버튼으로 뜹니다. 게임 마크는 `scripts/make-logo.js` 가 Galmuri 비트맵 글꼴과 스프라이트로 그립니다.

## 조작

아래는 기본 키다. 1~3 · Esc · P · N · F1~F12 를 뺀 모든 키는 설정(O) → [키 설정 (PC)] 에서 바꿀 수 있다.

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Space / ↑ | 점프 (공중 점프) · ↓+Space 발판 아래로 |
| Z · X · C | 스킬 (Z는 3타 콤보, X 범위기, C 이동·방어기) |
| Shift | 대시 회피 (무적, 잔상) |
| Tab · E · 1~3 | 포켓몬 교대 → 등장 순간 교체 스킬 발동 (쿨타임 3초) |
| Q | Z기술 (Z크리스탈 보유, 재사용 45초) — 화면 안 모든 적에게 강력한 일격 |
| V | 영구 메가진화 (3단 진화 + 메가스톤) |
| F / ↑ (시내) | 포켓몬센터: 파티 전원 회복 + 쓰러지면 다시 일어날 자리(몇 번이고) · 자판기: 가끔 강화 아이템, 아니면 오렌열매 (시내마다 1회) · 아머까오 정거장: 공중날기 |
| F / ↑ (샛길 끝) | 기술머신 가동: 카드 3장을 하나씩 뒤집고(클릭·1~3) 1장 확정(Enter). 기술 카드는 Z·X·C 중 바꿀 자리를 고른다 |
| Esc / P | 일시정지 · N 소리 |
| M · I · O | 지도(탐험한 곳, 1~5 로 지방 탭) · 가방(포켓몬별 장착 아이템·기술) · 설정 — HUD 왼쪽의 「가방 I · 지도 M · 설정 O」, 일시정지 메뉴의 「설정」으로도 연다 |
| ↓ + Space (철창 위) | 아래 방으로 내려가기 |
| F1 (로비) | 디버그: 모든 포켓몬 정화 수 해금 → 도감 등록 |
| F2 (전투) | 디버그: 이 지방 최종 보스방으로 순간이동 |
| F3 (전투) | 디버그 패널: 챕터 1~5 · 입구·시내·중간 보스·지방 보스·히든 성소·기술머신·보물방으로 순간이동, R 정화한 보스 다시 싸우기, 공중날기 전부 해금, 파티 회복 |
| F4 (전투) | 디버그: 성장 한 단계씩 (2단 → Z크리스탈 → 3단 → 메가) |

## 구조

- `scripts/fetch-assets.js` — SpriteCollab/PokeAPI 에서 에셋(도트·초상화·공식 아트워크, 무한다이맥스 포함)을 받고 `public/assets/manifest.json` 생성. 404 모션은 건너뛰고 PokeAPI 기본 도트를 백업으로 받음.
- `scripts/fetch-items.js` (`npm run fetch-items`) — 가방·HUD·줍기 알림·땅에 떨어진 아이템에 보이는 본가(소드실드·스칼렛바이올렛) 가방 아이템 그림을 `data/items.js` 의 `art` 이름으로 받아 `public/assets/items/<id>.png` 에 두고 manifest 의 `items` 에 적는다. 화면 크기에 맞춰 곱게 줄여 쓰고(`Textures.itemArt`), 못 받은 아이템은 도트 아이콘으로 대신한다.
- `src/systems/SpriteLoader.js` — `AnimData.xml` 파싱, 8방향 시트에서 오른쪽(2행)·왼쪽(6행)만 잘라 애니메이션 등록, 발 위치·몸통 크기 자동 측정.
- `src/systems/Fx.js` — 히트스톱, 카메라 쉐이크, 백색 점멸, 바닥에 튕기는 속성 파티클, 절차적 베기 궤적, 잔상, 데미지 텍스트.
- `src/game/` — 플레이어(파티·교대·메가), 스킬, 야생 적 AI, 보스, 전투·상성 계산, 월드 생성.
- 다섯 챕터 = 다섯 지방 (`data/stages.js` 의 `STAGES`): 관동 → 성도 → 호연 → 신오 → 하나(최종장). 챕터마다 지역 색·배경·로어·지형 비율과 보스 진용이 있다.
  - 관동: 중간 보스 롱스톤 · 팬텀(→메가팬텀) · 후딘(→메가후딘) → 지방 보스 뮤츠 · 히든 강철톤 (블루시티 동굴 아래) — 모두 전용 패턴
    - 롱스톤·강철톤(`Boss.js` 의 `onix`): 땅속으로 사라져 흙먼지 줄을 끌며 다가오다 발밑 표시 → 바위 분수와 함께 솟구침(강철톤은 2~3연속) · 천장 낙석(바닥에 떨어질 자리 표시) · 바닥을 쓰는 몸통 돌진(벽을 들이받으면 낙석) · 포물선 바위 · 강철톤 아이언헤드 내려찍기 + 쇠 파편 부채 · 2페이즈 지진(바닥 전체, 발판 위만 안전)
    - 후딘→메가후딘(`alakazam`): 순간이동 직후 사이코빔 3갈래(메가는 3연속) · 숟가락 부메랑 · 염동력 격자(세로 기둥이 짝·홀 번갈아, 메가는 가로 줄 추가) · 미래예지(서 있던 자리가 늦게 터짐, 메가는 3번) · 메가 전용 사이코웨이브(몸 둘레를 돌던 구슬 8개가 소용돌이로 퍼짐)
    - 뮤츠(`mewtwo`): 사이코브레이크(머리 위에서 기를 모은 뒤 거대한 파동 고리 — 닿는 순간 대시 무적으로 뚫는다, 폭주하면 두 겹) · 염동력 파편(바닥을 뜯은 바위가 보랏빛으로 떠올라 하나씩 날아옴) · 순간이동 + 섀도볼 난사(폭주하면 두 번) · 체력 50%에서 폭주하자마자 사이코브레이크
  - 성도: 방울탑을 위로 오르며 라이코 → 앤테이 → 스이쿤 → 꼭대기 칠색조 · 히든 전룡 — 모두 전용 패턴
    - 라이코(`raikou`): 번개 기둥(플레이어 자리부터 양옆으로) · 전광석화 돌진(지나간 바닥에 전기 자국, 2페이즈는 되돌아 한 번 더) · 방전(사방 번개 탄 + 몸 둘레 전기장)
    - 앤테이(`entei`): 화염 분출(바닥에서 불기둥이 플레이어 쪽으로 차례로, 2페이즈는 반대편 끝에서도) · 화염방사(고개를 틀며 1초) · 분화 내려찍기(착지하면 양옆으로 불길)
    - 스이쿤(`suicune`): 절대영도(냉기를 모은 뒤 양옆으로 얼음 기둥 파도 → 바닥이 얼어 밟으면 느려짐) · 오로라빔 바닥 쓸기 · 싸라기눈 · 물 위를 미끄러지는 돌진(물보라 자국)
    - 칠색조(`hooh`): 성스러운불꽃 폭격(아레나 위를 가로지르며 검붉은 불꽃탄 → 떨어진 자리에 불길 장판) · 폭풍 날개짓(플레이어를 밀어내는 바람 + 불꽃 깃털 부채, `Player.wind`) · 불꽃 깃털 연사 · 체력 30%에서 한 번 불사조 부활(불꽃에 휩싸여 체력 60%로) → 화면 전체 불꽃 탄막(천장 불꽃비에 빈틈 두 곳 + 사방 불꽃 고리 두 번)

- 가방(I) 화면: 위쪽 1~3 탭으로 포켓몬을 한 마리씩 본다 — 진화 단계·체력·경험치·능력치·아이템 효과, 장착 칸 5개, 기술 Z·X·C. 아래 왼쪽은 [도구](장착하지 않은 아이템 전부 + 중요한 물건 Z크리스탈·메가스톤) / [기술](그 포켓몬이 배운 기술 전부) 두 탭, 아래 오른쪽은 고른 것 설명과 버튼(장착하기 · 가방에 넣기 · Z/X/C 자리에 넣기 — 이미 다른 자리에 있으면 맞바꿈). 기술머신으로 바꾼 원래 기술도 배운 기술(`members[i].learned`)에 남아 상황마다 다시 넣을 수 있다(`Player.setSkill`). 쿨타임은 자리에 남고, 연타 기술(쿨타임 없음)은 Z 자리 전용. 키보드: 1~3·Q/E 포켓몬 · Tab 도구↔기술 · ←→ 고르기 · Enter 장착/빼기 · Z·X·C 고른 기술을 그 자리에.
- `src/systems/ProjectileRenderer.js` — 투사체를 속성별 픽셀 도트(불꽃 물방울·초승달 잎날·물총알·번개·영혼 구슬·바위·쇠 파편·염동력 파편·숟가락 등)로 그리고 꼬리 파티클·발사 섬광·속성별 적중 연출을 붙인다. 진화할수록 크기·판정 반경이 커진다(`TIERS[].proj`: 1단 1 · 2단 1.45 · 3단 1.9 · 메가 2.3). 2단부터는 투사체를 감싸는 기운과 적중 충격파 고리, 메가는 십자 섬광이 더해지고 꼬리·파편이 늘어난다.
- 설정(O, `systems/Settings.js` — 이 기기 브라우저에 저장): 볼륨(효과음·컷신 영상) · 소리 켬/끔(N) · 타격 흔들림(내 공격이 맞을 때) · 피격 흔들림(내가 맞을 때 · 보스 공격 · 폭발, 0~150%, 0이면 끔 — `Fx.shake` 의 kind 'hit' / 그 밖) · UI 크기(터치 조이스틱·버튼 80~140%, 아래 버튼은 오른쪽 아래 구석·조이스틱은 왼쪽 아래 구석 기준으로 커지고 위쪽 줄은 HUD 와 겹치지 않게 120%까지) · 패드 투명도(터치 조이스틱·버튼 0~100%, 0%면 안 보여도 누르면 된다 — 위쪽 지도·가방·설정 줄은 다시 찾을 수 있게 40% 아래로는 안 내려간다) · 터치패드 켬/끔 · 기본값으로. 막대를 끌거나 −/+ 로 조절하고, 흔들림·볼륨은 손을 떼면 미리 한 번 보여 준다(뒤로 게임 화면이 비친다). 터치패드 위쪽 줄에도 [설정] 버튼.
- 키 설정 (설정 → [키 설정 (PC)]): 이동·점프·대시·스킬 Z/X/C·교대·조사·Z기술·메가진화·지도·가방·설정 17가지 동작의 키를 바꾼다(예: Z·X·C → Q·W·E 나 A·S·D). 칸을 누르고(키보드는 ↑↓←→ 로 골라 Enter) 새 키를 누르면 끝, Esc 는 취소. 다른 동작이 쓰던 키를 고르면 두 동작의 키를 서로 맞바꾼다. 1~3 · Esc · P · N · F1~F12 는 고정. 바꾼 키는 HUD(스킬 구슬·Z기술·가방/지도/설정 글자) · 처음 안내 · 일시정지 조작법 · 지도/가방 창 안내에 바로 반영되고, [기본 키로] 로 되돌린다. 저장은 `pokecells.settings` 의 `keys` (`GameScene.bindKeys` 가 바뀔 때마다 다시 묶는다).
- 지도(M, `systems/MapView.js`): 방 블록(지역 색 + 밝은 외곽선) · 문 통로 · 안 가 본 길 점선. 위쪽 [ 1.관동지방 | … | 5.하나지방 ] 탭(1~5)으로 들른 지방을 오간다. 핀: 포켓몬센터 · 아머까오 · 지방 보스(큰 해골)·중간 보스(작은 해골, 정화하면 회색) · 히든 전설(보라 ?, 옆방만 봤으면 흐릿한 힌트) · 기술머신 · 보물 · 상처약 · 현재 위치. 가방(I)과 탭 전환, 「닫기」 버튼, 끌어서 이동·＋/– 확대 (휴대폰 대응).
- 세계관: 무한다이노의 독기에 침식당한 다섯 지방. 지역에 처음 들어서면 할로우 나이트식 지역 타이틀, 부서진 로어 표지판은 F / ↑ 로 읽는다.
- `src/systems/TreeArt.js` — 고밀도 픽셀 고목 생성기 (`drawDetailedPixelTree`): 뿌리·휜 줄기·갈래 가지, 4단 명암+디더링 수피, 빛나는 수액 균열·나무 구멍, 수백 개 잎 뭉치, 거미줄, 흔들리는 덩굴(`drawVine`). 배경 숲 실루엣도 같은 생성기로 그린다.
- `src/game/Level.js` — 타일 번호(`T`)·발판 집합과 바닥 찾기(`groundYAt`)만 남은 공용 도우미. 방 안 지형(계단식 언덕·깊은 구덩이+나무다리·공중 섬·석조 계단·탑과 다리·지붕에 올라서는 집·발판 더미)은 `World.js` 가 지역별 비율(`terrain`)로 깐다. 웨이브 없이 미리 정한 자리에 적이 있다가 다가가면 나타나고, 관문은 아레나 입구만 닫힌다.
- `src/game/Props.js` — 집·포켓몬센터·자판기·아머까오 정거장·가로등·고목·석상·울타리·부서지는 상자·수풀/버섯 등 소품을 절차적 도트로 그리고 배치, 시내 상호작용.
- `src/game/Trainer.js` — 아레나 뒤 단상의 세뇌된 트레이너(난천 · 레드): 28×48 절차적 도트(평소 · 손짓 · 풀려난 모습), 천장에서 머리·두 손으로 이어진 꼭두각시 실, 손짓(`gesture`) · 몬스터볼 던지기(`throwBall`) · 실이 끊어지는 해방(`release`) · 대사(`say` → 화면 아래 대사 상자).
- 배경 (`systems/Textures.js`): 지방마다 원경 하늘 — 관동 무한다이노의 폭풍우 · 성도 재가 흩날리는 호박빛 황혼과 큰 달 · 호연 폭풍우와 비 · 신오 시공의 금이 간 보랏빛 밤 · 하나 진홍 소용돌이와 육각 핵. 지역마다 랜드마크 중경(`LANDMARKS`, `data/stages.js` 의 `bg`) — 부서진 오박사 연구소 · 상록숲 고목 · 회색시티 박물관과 프테라 화석 · 포켓몬타워와 묘비 촛불 · 실프 사이버 빌딩과 배양 캡슐 · 블루시티 동굴 결정 · 연두마을 기와집과 도리이 · 금빛 라디오타워와 멈춘 리니어 · 인주 불탄 기둥과 단풍 · 구름 위 방울탑 · 등화 해안 절벽 등대 · 굴뚝산 화산과 케이블카 · 해저동굴 아치와 빛줄기 · 하늘기둥 석기둥과 오로라 · 축복시티 설경 · 천관산 설산 신전 · 챔피언로드 부유 바위 · 창기둥과 시공 균열 · 뇌문시티의 무너진 대관람차와 네온 다리 · 용나선탑 · N의 성을 뚫은 붉은 결정. 지방 강조색에 물든 안개 낀 실루엣이라 어두운 하늘에서도 모양이 읽힌다.
- `src/scenes/` — 로딩, 도감·파티 편성 로비, 인트로 컷신(`CutsceneScene.js` — ESC/Space · 오른쪽 위 「건너뛰기 ▶▶」 버튼 · 화면 아무 데나 두 번 탭으로 스킵), 던전, HUD.
- 인트로 컷신 영상: 원본은 `assets-src/cutscene/`(`eternatus.mp4` 무한다이노, `bond-flame.mp4` 유대의 불꽃). `npm run make-videos` 가 자르고(유대의 불꽃은 0~5초, 포켓몬 반응 전까지) 가볍게 다시 인코딩해 `public/assets/video/` 에 둔다. 단일 HTML 빌드는 이 영상을 파일 안에 담는다. 레드가 끌려가는 장면은 아직 도트 연출이며, 영상을 못 틀면 앞 두 장면도 도트 연출로 대신한다.
- UI: 할로우 나이트풍. 장식 문양 없이 흐려지는 가는 선, 광택 있는 유리·금속 부품(몬스터볼 HP 가면, 몬스터볼 테두리 메가 게이지 그릇, 스킬 구슬), 프리텐다드·Cinzel 글꼴(OFL — `scripts/make-fonts.js`). 캔버스는 논리 640x360 의 2~3배(`config.RES`)로 그려 글자·광택을 매끈하게 하고, 도트는 그대로 크게 보인다. 로비는 파티 편성 / 스킬 / 정화 진행도 탭(Q·E).
- 세뇌·정화: 모든 적은 무한다이노에게 세뇌된 상태로 보라·자홍 틴트, 붉은 안광과 궤적, 발밑 침식 오라·검붉은 연기, 1.5~3초마다 글리치(RGB 분리)를 두른다(`Enemy.syncCorruption`, `GameScene.drawCorruption`). 쓰러뜨리면 검보라 껍질이 유리처럼 깨지고 → 하얀 섬광 → 본래 색으로 돌아와 하트를 띄운 뒤 → 몬스터볼 빛줄기처럼 귀환한다(`GameScene.purify`). 같은 포켓몬을 10번 정화하면 도감에 등록된다.

저장 데이터(도감 해금, 정화 수, 파티)는 브라우저 `localStorage` 의 `pokecells.phaser.v1` 키에 있습니다.
